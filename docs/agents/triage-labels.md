# Triage label vocabulary

This repository uses the default triage labels. The `triage` skill and other engineering skills will apply these labels when moving issues through the triage workflow.

## Label mapping

| Role | Label string |
|------|--------------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

## Notes

These are the canonical triage roles. If your issue tracker uses different label names (e.g., `bug:triage` instead of `needs-triage`), edit the "Label string" column above so the skills apply the correct labels.
