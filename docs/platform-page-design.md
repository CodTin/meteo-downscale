# 气象降尺度平台页面详细设计（决策草案）

**状态：历史草案。** 本轮已确认的页面分类与功能行为见根目录 [GLOSSARY.md](../GLOSSARY.md)；下文保留设计讨论的原始提案，未确认标记及范围表述以最终规格为准。

**依据**：[平台产品设计](product-design.md)与[模型技术报告](refs/TECH_DOC.md)。本稿以业务用户的页面职责为主；页面边界和交互细节由 [Wayfinder 页面设计地图](https://linear.app/yu-xiao/issue/YU-271) 中的决策票确认。

## 设计终点与边界

首版面向区域气象分析/预报人员，消费**已发布**的 3 km 集合预报：发现天气过程、查看局地结构、比较 EC 与 AI、判断成员分歧、复核历史表现并导出结果。历史回放与未来业务生产使用同一套分析页面，以明确的数据模式和实际起报时间区分。研究评价独立于业务主导航；内部模型调参、任务协作、预警发布和任意 GIS 编辑均不进入本页面树。

技术报告中的 MRA-ResUNet 融合先验、Topo-EDSR 条件均值与 CSC-ResDiff 集合成员，分别支撑按需解释与正式集合产品。业务默认显示十个成员在物理单位下计算的集合均值，融合先验和条件均值只在确有对应批次数据时作为解释对象出现。现存输入和标签不等于已发布的 AI 产品。

### 跨页面共享状态

所有业务页面显示并传递：`数据模式 → 起报周期 → 有效时刻/lead → 变量与表达方式 → 业务区域/点位 → 产品批次`。同一页面内的二维/三维、比较和集合视图使用同一已发布产品与有效网格掩膜。链接打开、切换周期和导出启动时重新校验发布状态；不可用时说明原因，不自动选择邻近时刻、旧批次或上次结果。UTC 是数据时间基准，界面同时清晰展示起报、有效时刻和 `+lead`。

TP 累计窗口与 `f000` 口径未核实前，仅在明确标注的诊断视图查看原值；总览业务摘要、EC–AI 差值、阈值判断、区域统计、验证结论和正式导出都不包含 TP。集合均值、spread 和超阈值比例只对十个完整有效成员计算；“集合超阈值比例”不称为经校准的事件概率。

## 第二层：各页面及子页面

### 1. 预报总览

默认进入最新**已发布**周期和浏览器保存的矩形业务区域；如果仅有历史回放，标题显式写“历史周期”及日期。顶部显示实际起报时间、处理完成时间、可用时效、空间覆盖、成员完整性和缺失原因。四个平等的要素入口为温度、气压、10 m 风和降水；降水在口径未核实时呈不可用于业务判断状态。

总览卡片展示区域温度高/低值、气压低值、风速高值及位置、有效时刻和单位；另有区域时间变化、集合 spread 较高处与已启用阈值的成员支持度。卡片只提供线索，不输出综合风险等级。点击卡片带着周期、时效、变量、区域和批次进入二维地图、局地分析或集合页。无可发布数据时显示空状态与预报目录入口。

### 2. 预报分析

这是同一个分析工作区的六个可直达子页面。共享上下文栏可选周期、valid time、变量、业务区域并查看发布状态；时间轴只列已发布时效，缺口保留空档。

| 子页面 | 具体职责 | 关键结果与跳转 |
| --- | --- | --- |
| 二维地图 | 默认查看 AI 3 km 集合均值；切换合规的数据层、有限多变量组合和时间播放；显示图例、单位、色阶、有效掩膜与数据来源。地图点击取最近 3 km 网格点，框选矩形区域。 | 点或区域进入“点位/区域分析”；对比、集合、三维视图沿用相同位置和时效。 |
| 三维地形 | 在已对齐 DEM 上给气象场着色，显示高程单位与垂直夸大倍数；切换 AI、EC、允许的差值、spread 或成员；支持地表点取值和沿线 DEM/气象量剖面。 | 与二维共享变量、时效、选区、批次；地形相关性不得直接解释为因果改进。 |
| EC–AI 对比 | 同周期同 lead 的“EC 10 km（插值至 3 km 网格）｜AI 集合均值｜AI−EC”三栏联动；可按需加入 GFS 输入差异。差值显示符号、单位、统一色阶与共同有效掩膜。 | 点击差异区进入点位/区域分析；“预报不同”不表述为“AI 更准确”。TP 在口径核实前禁用正式对比。 |
| 集合与阈值 | 在 AI 均值、单成员、spread 与超阈值成员比例之间切换；风速按每成员 U/V 先求模。展示十成员分布及 `7/10` 一类原始计数；温度支持 `>`/`<`，风速支持预设与自定义阈值。 | 点位查看成员值，区域定位支持度分布；对未校准结果使用“集合超阈值比例”。 |
| 点位/区域分析 | 点位显示点击坐标、实际网格坐标、AI/EC/差值、十成员值与逐小时时间序列；矩形区域显示面积加权均值、极值及位置、区域均值/最大值的时间变化。缺失时效断线。 | 点位和一个默认业务区域可在当前浏览器轻量保存；CSV 导出传递当前查询条件。 |
| 跨周期演变 | 固定 valid time，列出已发布且该时刻可用的多个 cycle 与各自 lead；比较同一变量、网格、区域上的预报变化；每个 cycle 如需 EC 差值，仍与自己的 EC 配对。 | 少于两个可比周期时说明原因；可跳到对应周期地图或个例验证。 |

### 3. 预报目录

| 子页面 | 具体职责 |
| --- | --- |
| 周期列表 | 按起报时间倒序列已发布或部分可用周期；筛选历史回放/业务生产，显示可用 lead 范围、覆盖范围、处理时间与缺口。默认“最新”仅指最新已发布周期。 |
| 周期详情 | 按 lead 和覆盖区域查看输入、推理、检查、发布状态；显示缺失成员/时效、失败原因、实际使用的已发布批次、模型标识及溯源。能进入对应分析页。只读，不提供业务用户重试或发布操作。 |
| 有效时刻检索 | 输入目标 valid time，返回可覆盖它的已发布周期和对应 lead；区分没有预报、未发布和区域无效三种情况。进入分析或跨周期演变。 |

生产状态不另设独立主导航页面；目录详情是状态与溯源的集中入口，分析页面提供当前产品的状态抽屉。是否另需运营管理端是待确认的范围决策。

### 4. 天气过程发现

单页设置周期、业务区域、变量、已发布有效时刻范围；结果按温度高/低值、气压低值、10 m 风速高值、相邻有效小时的区域均值变化，以及风/温阈值的成员支持度分组。每条结果显示值、单位、网格位置、valid time、lead、区域与计算口径。不同指标不合成综合风险分。结果跳转二维地图、集合视图或局地分析，保持产品批次。TP 业务检索等待累计口径核实。

### 5. 历史验证

| 子页面 | 具体职责 |
| --- | --- |
| 验证概览 | 按变量、区域、lead、周期筛选具有同一 valid time 和共同有效掩膜的 AI、EC 与 3 km 参考分析场；展示可用样本数、RMSE、MAE、CRPS 及验证条件。样本独立性未确认时隐藏“相对 EC 改进”结论。 |
| 个例详情 | 对指定周期/时刻显示 AI、EC 与参考场及对应误差，说明参考场不是站点观测；记录样本是否与训练/调参隔离、缺失范围和计算口径。回跳同状态分析页。 |

业务验证不展示消融或模型版本竞赛。无参考场、同口径产品或独立样本时，用原因解释不可验证状态。

### 6. 导出中心

| 子页面 | 具体职责 |

### 7. 研究评价（独立入口，范围待确认）

| 子页面 | 具体职责 |
| --- | --- |
| 基准指标 | 展示技术报告中的 RMSE、MAE、CRPS 和样本范围，明确主对比实验中方法间样本量不同、T2m 未全面领先；避免直接转写为业务预报技巧。 |

## 待决策与依赖

1. 主导航是否收录“研究评价”独立入口，以及研究用户如何进入，不影响业务导航结构。
2. 是否需要面向运营人员的生产/重试/发布管理页面；目前只设计业务用户的只读状态。
3. 预报分析的六个子页面是否保留为直达页面，或将点位/区域分析、集合探索做成可分享的工作区面板。无论哪种形态，共享状态和数值口径不变。
4. 预报目录与总览、分析之间的进入/返回规则；特别是切换周期后目标 valid time 缺失的处理。
5. 研究评价和历史验证的信息隔离、证据门槛、缺数据状态。

这些问题进入 Wayfinder 页面决策票；完成逐页决策后再把本稿标为正式页面规格。
