# TanStack Table for Data Grids

We chose **TanStack Table** (28.5M weekly downloads) as a headless table library with sorting, filtering, and pagination that integrates seamlessly with shadcn/ui. The headless architecture provides complete control over rendering while the library handles complex state logic (multi-column sorting, filter combinations, virtualization for large datasets).

This explicitly rejects AG Grid (300KB+ bundle, paid license for enterprise features). For a scientific platform displaying ensemble member tables, cross-cycle evolution grids, and export task lists, TanStack Table's flexibility and MIT license are essential.
